# Jev 群知识迭代

目标：每日从指定群的完整新增对话中整理可复用经验，结合原始证据和已有知识由 Jev 审核；同时改善多轮求助判断和回复质量复盘。Grok 负责提取，Jev 负责判断，知识库负责检索。评估置信度不等同于事实核验。

## 验收要求

- [x] 独立知识开关、群白名单、每日时间、审核发布模式；默认不扩大现有答疑范围。
- [x] 每日持久化任务、按消息分页、断点恢复、有限重试、并发租约；不因单页上限丢弃全天剩余消息。
- [x] 抽取包含原始消息 ID、问题、环境、解决步骤、结果；机器人回复不能独自证明方案有效。
- [x] Jev 评估支持度、复用价值、解决状态、敏感性；无依据/低置信度不自动发布。
- [x] 对照已有知识进行语义重复、补充、冲突判断；变更保留原文和版本；人工维护内容不会自动覆盖。
- [x] 群和租户隔离、成员退出、插件禁用和删除状态在外发与发布前复查。
- [x] 控制台可查看每日任务、候选、证据、原因并审核、重试；发布幂等且索引失败可恢复。
- [x] 未解决问题支持后续解决证据补充，知识提取与机器人质量复盘分开。
- [x] 多轮求助理解相关上下文；复盘允许零问题，结论有原始证据。
- [x] 有针对性的单元、真实 PostgreSQL 集成、前端与运行时验证；线上启用仅限已授权群。

已于 2026-09-21 完成部署与真实归档验收；历史阶段描述保留，下方最终验收为当前状态。
