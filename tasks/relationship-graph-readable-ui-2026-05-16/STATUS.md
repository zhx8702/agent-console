# Relationship Graph 可读性 / 布局优化

日期：2026-05-16

## 用户反馈

- `Actions / 关系图控制台` 固定占住空间，其他内容展示空间不足。
- 关系图谱视觉效果奇怪，可视化程度不高。
- 节点显示 user id / wxid，普通人看不懂；希望优先显示昵称。

## 目标

1. 调整 Relationship Graph 页面布局，让控制区不再遮挡/挤压主要图谱展示。
2. 图谱节点/边展示更可读：普通用户能看出“谁和谁有什么关系”。
3. 节点 label 优先使用昵称/alias/profile 名称；没有昵称时再 fallback 到 user id / wxid。
4. 不泄露原始聊天内容。
